О проекте

Простой обмен файлами, который не лезет в облако

Файло обменник создан, чтобы переносить файлы между телефоном и компьютером быстро и без лишних действий.

🎯

Простота

Никаких аккаунтов и настроек. Выбрали файл — показали QR — всё передано.

🚫

Без облака

Файлы не копируются на сторонние серверы: передача идёт между вашими устройствами в одной сети.

📱💻

Две платформы

Одно приложение на Android и Windows — обмен работает в обе стороны между ними.
